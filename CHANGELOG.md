# Changelog

This specification follows [Semantic Versioning](https://semver.org/).

## 1.0.0 — 2026-11-08

- First public version: character rules, the two name shapes, 13 types, 17 components,
  platform-fixed names, custom-property metadata, lifecycle and rename rules, and a validation
  regular expression.
- `AGENTS.md` and `CLAUDE.md` so AI agents apply the specification.
- `scripts/check-repo-name.sh`: name checker with explained errors, owner rules, platform
  names, organization audit (`--org`) and a self-test that cross-checks the SPEC regex.
